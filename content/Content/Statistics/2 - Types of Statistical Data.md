**Data** is a collection of information that we collect and analyse, for
example ages, heights, or survey responses. In statistics, a **variable**
is whatever characteristic we measure or record about each observation.

## Univariate vs. bivariate

- **Univariate data** involves a single variable. It's used to describe
  and summarise one characteristic of a group — e.g. the heights of a group
  of students, or a set of test scores.
- **Bivariate data** involves two variables considered together, so we can
  investigate whether a relationship exists between them — e.g. study time
  paired with test score, or height paired with weight. (Covered in
  [[7 - Bivariate Data and Scatterplots]] onward.)

## Categorical vs. numerical (for univariate data)

|                     | Categorical data                                                           | Numerical data                                         |
| ------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------ |
| What it is          | Data that falls into categories or groups                                  | Data that can be measured or counted                   |
| Examples            | Colours, religion, age groups (e.g. 0–9, 10–19), soccer teams, hair colour | Height, test score, number of chairs in a room, salary |
| Can you average it? | No, it doesn't make sense to find a "mean" soccer team                     | Yes                                                    |

A quick test: if you can sensibly put the data into a frequency table of
*groups/labels*, it's categorical; if you could sensibly draw a histogram
or calculate a mean from it, it's numerical.

Numerical data is sometimes further split into:
- **Discrete** — countable, with gaps between possible values (e.g. number
  of chairs — you can't have 2.5 chairs).
- **Continuous** — measurable, able to take any value in a range (e.g.
  height, weight).
